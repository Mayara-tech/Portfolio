01 / About

From operations to building solutions.

Technology should not just digitize an inefficient process. It should help us rethink it.

I am an IT professional with experience in software engineering, technical leadership, project management and technology operations. Today I supervise an IT support team and, alongside that, I build applications, automations and AI solutions for problems I come across in day-to-day operations.

I started close to operations, in technical support, networking and infrastructure, helping people and keeping systems running. That background shaped how I build software: before choosing a tool, I want to understand where the process gets stuck, who depends on it and what happens when it fails.

My education follows the same path: Software Engineering at the University of Brasília, IT Management, a graduate degree in Network Engineering, an MBA in Project Management and a degree in Agribusiness Management, which taught me to look at cost, supply chains and operations before technology.

  1. Understand before building

    I talk to the people who use the process, observe the routine and find where it actually breaks down.

  2. Question the process

    Not every step needs to exist. Sometimes the best automation is removing a step altogether.

  3. Build what is needed

    Clear rules, reliable data and AI where it adds value. Code does the math, AI interprets and writes.

  4. Document and improve

    Procedures, decisions and metrics are recorded so the solution keeps working without depending on me.

01Applied AI · Product

Artificial intelligence for property management

A set of solutions that brings AI into the document-heavy routine of a condominium management office, right where the work happens.

  1. audio, notice, spreadsheet
  2. rules + AI
  3. minutes, notice, dashboard
  • LLMs
  • Skills and agents
  • Python
  • Context engineering
  • Document analysis
  • HTML
Problem
Meeting minutes, notices, balance sheets and reports were read, interpreted and written by hand. Hours of work and rework on very similar content.
Solution
Meeting minutes generated from audio and agenda, drafted notices, balance sheet analysis and exported spreadsheets turned into readable dashboards. Calculations are done in code. AI interprets and writes.
My role
Solution design, context and prompt engineering, building the skills, testing with real documents, exception handling and integration into the existing workflow.
Goal
Reduce manual document work while keeping human review where accountability is required.

02IT operations · Data

Management view of a support operation

Cross-checking what the team reports in messaging channels against what actually becomes a ticket, to reveal recurring issues and gaps.

  1. messages
  2. tickets
  3. correlation
  4. management dashboard
  • Node.js
  • Playwright
  • SQLite
  • SQL
  • YAML
  • HTML
Problem
Alerts arrived through group chats while tickets lived on a separate platform. Without matching the two, recurring problems and requests that never became tickets stayed invisible.
Solution
Local collection from both sources and cascading correlation: ticket number when mentioned, then location, type and time window. Rules live in editable files and AI is used only for the period summary, which keeps costs low and results auditable.
My role
Process mapping, defining correlation and classification rules, development and dashboard design.
Goal
Turn scattered communication into information for decisions and continuous improvement.

03Infrastructure · Automation

Automated workstation standardization

A single routine that sets up every computer to the same standard, from user backup to final validation.

  1. backup
  2. network and domain
  3. software
  4. validation
  • PowerShell
  • Windows
  • Active Directory
  • Networking
Problem
Preparing each machine took a long sequence of manual steps, repeated computer by computer, with a real risk of skipping steps and ending up with inconsistent setups.
Solution
A script that runs the whole flow: user file backup, network and DNS settings, domain join, software installation based on the machine profile, profile cleanup and validation checks. It comes with a checklist for whoever runs it.
My role
Analysis of the manual process, ordering steps and checks, script development and testing in different scenarios.
Goal
Standardize machine setup and eliminate step-by-step manual work.

04Web app · Data

IT inventory control

An installable mobile app to track equipment and supplies, with stock levels that never depend on manual entry.

  1. stock in and out
  2. database computes balance
  3. restock alert
  • React
  • Supabase
  • PostgreSQL
  • PWA
  • Vercel
  • Python
Problem
Equipment and supplies were tracked by hand, with no clear view of stock levels, movements or items running low.
Solution
Items, categories, stock in and out, destinations, minimum levels, reports and alerts. The balance is never typed in: the database calculates it from movements, so the screen can never drift from the real stock. It started as a Python desktop tool and evolved into a web app.
My role
Requirements, data modeling and business rules, development and deployment.
Goal
Make inventory control proactive, warning before something runs out instead of noticing afterwards.

05Data · Product

Market intelligence platform

A structured, searchable database of companies in a sector, built from scattered public sources.

  1. public sources
  2. collection and cleaning
  3. searchable database
  • Python
  • Streamlit
  • SQLAlchemy
  • SQLite
  • Web scraping
Problem
Mapping the companies in a market relied on manual research, with no database to search, compare or reuse what had already been found.
Solution
An application that collects, cleans and catalogs information with explicit trust rules: automation never confirms a record on its own, conflicting sources become a flagged discrepancy with both pieces of evidence, and no value is overwritten without history.
My role
Product concept, choosing the relevant data, collection and cleaning logic, database structure and usage guidance.
Goal
Replace manual searching with a reliable in-house database ready for analysis.
